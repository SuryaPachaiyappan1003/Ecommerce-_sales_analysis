# E-Commerce Product Analysis

## 📌 Project Overview

This project focuses on analyzing e-commerce product data to understand product performance, pricing, discounts, customer interest, ratings, reviews, stock levels, and sales potential.

The project uses Python, SQL, Excel, and Power BI to perform data analysis and create an interactive dashboard.

---

## 🎯 Objectives

- Analyze product and category performance
- Identify high-performing products
- Analyze product pricing and selling prices
- Study discount patterns
- Analyze customer ratings and reviews
- Identify low-stock and high-stock products
- Analyze brand and sub-category performance
- Calculate product sales potential
- Create an interactive Power BI dashboard

## 📊 Dataset

The dataset contains **500 e-commerce products** with the following columns:

| Column | Description |
|---|---|
| Product_ID | Unique product identifier |
| Product_Name | Name of the product |
| Category | Main product category |
| Sub_Category | Product sub-category |
| Brand | Product brand |
| Price | Original product price |
| Discount_Percent | Discount percentage |
| Rating | Customer rating |
| Review_Count | Number of customer reviews |
| Stock | Available stock |
| Selling_Price | Final selling price |
